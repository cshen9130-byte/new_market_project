详细说明：
实际请求：

https://mallapi.huofuniu.com/fund/info?app_id=hfnud0cqtrrnnul3kmp&reg_code=SR6089&sign=77dca370c4f711493f0bcfd323cfb819&tm=1788505389


签名说明：

对请求Query参数不包函sign参数，对参数key升序排序 ，按key=value拼接的结果，用&拼接后，再拼接上密钥计算这个字符串的md5哈希

sign = md5(`app_id=hfnud0cqtrrnnul3kmp&reg_code=SR6089&tm=1788505389ffb326c1ece5fa25552783c730d36666`) = 77dca370c4f711493f0bcfd323cfb819

SDK使用示例：
# 将fof99目录添加到Python搜索路径【这步很重要，否则执行脚本找不到请求类】
import sys
sys.path.append(r'E:\path\to\mall_sdk')

# 1、引入请求类
from fof99 import FundInfo

# 2、创建请求对象
appid = 'hfnud0cqtrrnnul3kmp'
appkey = 'ffb326c1ece5fa25552783c730d36666'
req = FundInfo(appid, appkey)  # 请求对象

# 3、设置请求参数，参考API文档
req.set_params(reg_code='SR6089')

# 4、发起请求， use_df=True表示结果返回pandas.DataFrame对象；use_df=False表示结果返回Python列表
res = req.do_request(use_df=True)

# 5、结果处理
print(res)
print(req.get_debug_info())
