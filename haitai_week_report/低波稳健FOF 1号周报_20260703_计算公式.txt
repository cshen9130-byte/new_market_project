低波稳健FOF 1号 周报计算公式说明
========================================================================
报告文件: 低波稳健FOF 1号周报_20260703.pdf
报告标题: 低波稳健FOF 1号
产品简称: 海泰1号
报告周区间: 2026-06-29 ~ 2026-07-03
数据截至: 2026-07-03
净值频率: weekly（周频，年化因子 periods_per_year = 52）
基准: 沪深300
计算脚本: haitai_week_report/generate_fof_weekly_report.py

符号约定
------------------------------------------------------------------------
  adj_nav(t)     = 截至日期 t 的复权净值
  csi300(t)      = 截至日期 t 的沪深300收盘价
  adj_nav_start  = 首日复权净值 = 1.0000（2023-12-29）
  adj_nav_end    = 末日复权净值 = 1.5816（2026-07-03）
  csi300_start   = 3431.1099（2023-12-29）
  csi300_end     = 4842.1740（2026-07-03）
  csi300_0626    = 4868.2210（2026-06-26，本周收益/基准对比的参照日前值）

一、数据准备
------------------------------------------------------------------------
1) 历史净值
   来源: 低波稳健FOF 1号合并净值.xlsx（2023-12-29 至 2026-06-26）
   2026-06-26 之后，按基金邮件净值的逐日涨跌幅叠加到合并净值尺度:
     adj_nav(t) = adj_nav(t-1) × [ email_unit_nav(t) / email_unit_nav(t-1) ]

2) 基准
   来源: 沪深300（代码 sh000300）
   净值文件中已有的日期直接取值；缺失日期由 akshare 补齐。

3) 周频处理
   对日频复权净值按 W-FRI 取每周最后一个交易日；
   若周末超过实际最后数据日，则截断到 week_end = 2026-07-03。

二、顶部 KPI（第一行）
------------------------------------------------------------------------
【1. 本周收益】= +0.08%
   公式:
     week_return = adj_nav(week_end) / adj_nav(prior_day) - 1
   说明:
     prior_day 为报告周内首个净值日（2026-06-29）之前最近一个交易日。
   代入:
     adj_nav(2026-07-03) = 1.5816
     adj_nav(prior_day) = 1.5816 / (1 + 0.0008) = 1.5803
     week_return = 1.5816 / 1.5803 - 1 = 0.000800 = +0.08%

【2. 今年以来】= +10.08%
   公式:
     ytd_return = Π(1 + month_return_i) - 1
   说明:
     使用日频原始净值，按自然月月末净值计算各月收益，再连乘得到 YTD。
     与下方“区间收益率”表中 2026 年“全年”一致。
   2026 年各月收益（来自报告表）:
     1月 +2.68%    2月 +0.67%    3月 -0.54%
     4月 +0.71%    5月 +2.46%    6月 +4.10%
     7月 -0.32%
   代入:
     (1 + 0.0268) × (1 + 0.0067) × (1 - 0.0054) × (1 + 0.0071)
   × (1 + 0.0246) × (1 + 0.0410) × (1 - 0.0032) - 1
     = 1.1008 - 1 = 0.1008 = +10.08%

【3. 运作以来】= +58.16%
   公式:
     total_return = adj_nav_end / adj_nav_start - 1
   代入:
     total_return = 1.5816 / 1.0000 - 1 = 0.5816 = +58.16%

【4. 最新净值】= 1.5816
   公式:
     end_nav = adj_nav(2026-07-03)
   结果:
     1.5816

三、顶部 KPI（第二行）
------------------------------------------------------------------------
【5. 夏普比率】= 2.84
   公式:
     sharpe = annual_return / annual_volatility
   说明:
     不扣除无风险利率，与历史周报口径一致。
   代入:
     sharpe = 20.03% / 7.06% = 0.2003 / 0.0706 = 2.84

【6. 年化波动】= 7.06%
   公式:
     period_return_t = adj_nav(t) / adj_nav(t-1) - 1
     volatility = std(period_return, ddof=1) × sqrt(periods_per_year)
   说明:
     周频下 periods_per_year = 52。
   结果:
     7.06%

【7. 最大回撤】= -2.86%
   公式:
     wealth(t) = adj_nav(t) / adj_nav_start
     drawdown(t) = wealth(t) / max_{s≤t} wealth(s) - 1
     max_drawdown = min_t drawdown(t)
   结果:
     -2.86%

【8. 超额收益（运作以来）】= +17.04%
   公式:
     bench_total = csi300_end / csi300_start - 1
     excess_total = total_return - bench_total
   基准代入:
     bench_total = 4842.1740 / 3431.1099 - 1 = 0.4113 = +41.13%
   超额代入:
     excess_total = 58.16% - 41.13% = 17.03% ≈ +17.04%
     （报告四舍五入显示为 +17.04%）

四、累计收益率走势图
------------------------------------------------------------------------
【产品累计收益率（图末端标注）】= +58.16%
   公式:
     fund_cum_return(%) = (adj_nav(t) / adj_nav_start - 1) × 100
   代入:
     (1.5816 / 1.0000 - 1) × 100 = +58.16%

【基准累计收益率】
   公式:
     bench_cum_return(%) = (csi300(t) / csi300_start - 1) × 100
   代入:
     (4842.1740 / 3431.1099 - 1) × 100 = +41.13%

【图中“本周区间”阴影】
   区间为 week_start = 2026-06-29 至 week_end = 2026-07-03。

五、区间收益率表
------------------------------------------------------------------------
【单月收益率】
   公式:
     month_return(年Y, 月M)
       = adj_nav(该月最后一个净值日) / adj_nav(上月最后一个净值日) - 1
   若该月没有净值，则显示 "-"。

【胜率】
   公式:
     win_rate = 正收益月份数 / 有数据月份数

【全年】
   公式:
     annual_return_year = Π(1 + month_return_i) - 1

--- 2026 年（胜率 71.43%，全年 +10.08%）---
  1月: +2.68%     2月: +0.67%     3月: -0.54%
  4月: +0.71%     5月: +2.46%     6月: +4.10%
  7月: -0.32%     8-12月: 无数据
  胜率 = 5 / 7 = 71.43%
  全年 = (1.0268)(1.0067)(0.9946)(1.0071)(1.0246)(1.0410)(0.9968) - 1
       = +10.08%

--- 2025 年（胜率 75.00%，全年 +10.94%）---
  1月: -0.55%     2月: +3.24%     3月: -0.25%
  4月: +0.26%     5月: +0.95%     6月: +1.17%
  7月: +0.38%     8月: +3.35%     9月: +0.32%
  10月: -0.41%    11月: +1.07%    12月: +0.99%
  胜率 = 9 / 12 = 75.00%
  全年 = Π(1 + 各月收益) - 1 = +10.94%

--- 2024 年（胜率 83.33%，全年 +29.51%）---
  1月: +1.11%     2月: +1.14%     3月: +2.52%
  4月: -1.33%     5月: +0.77%     6月: -0.16%
  7月: +0.78%     8月: +0.24%     9月: +3.40%
  10月: +15.48%   11月: +1.39%    12月: +1.75%
  胜率 = 10 / 12 = 83.33%
  全年 = Π(1 + 各月收益) - 1 = +29.51%

六、本周要点
------------------------------------------------------------------------
【策略表现：本周净值累计上涨 0.08%】
   使用 week_return = +0.08%

【周内最高点：周五升至 1.5816，创运作以来阶段新高】
   公式:
     week_high_nav = max(adj_nav(t)),  t ∈ [2026-06-29, 2026-07-03]
   结果:
     2026-07-03（周五）净值 1.5816

【市场环境：沪深300本周 -0.54%】
   公式:
     week_bench = csi300(week_end) / csi300(prior_day) - 1
   代入:
     week_bench = 4842.1740 / 4868.2210 - 1 = -0.00534 = -0.54%

【策略跑赢基准 0.62 个百分点】
   公式:
     week_excess = week_return - week_bench
   代入:
     week_excess = 0.08% - (-0.54%) = 0.62 个百分点

【运作情况：运作以来累计 +58.16%，最大回撤 -2.86%】
   分别使用 total_return 与 max_drawdown。

七、核心指标一览
------------------------------------------------------------------------
【成立日期】= 2023-12-29
   取净值序列首个交易日。

【运作天数】= 605 个交易日
   公式:
     trading_days = count_cn_trading_days(start_date, end_date)
   说明:
     使用 A 股交易日历（akshare 新浪交易日历）统计
     2023-12-29 至 2026-07-03（含首尾）之间的交易日数量。
   结果:
     605 个交易日

【初始净值】= 1.0000
   首日复权净值；若原始首值不为 1，则先整体归一化:
     adj_nav(t) = adj_nav(t) / adj_nav(首日)

【年化收益】= +20.03%
   公式:
     years = (end_date - start_date).days / 365.25
     annual_return = (adj_nav_end / adj_nav_start) ^ (1 / years) - 1
   代入:
     years = (2026-07-03 - 2023-12-29).days / 365.25 = 2.5106
     annual_return = (1.5816 / 1.0000) ^ (1 / 2.5106) - 1 = 0.2003 = +20.03%

【卡玛比率】= 7.00
   公式:
     calmar = annual_return / |max_drawdown|     （当 max_drawdown < 0）
   代入:
     calmar = 20.03% / 2.86% = 0.2003 / 0.0286 = 7.00

【日度胜率】= 62.02%
   公式:
     win_rate = count(period_return > 0) / count(period_return)
   说明:
     周频下 period_return 为相邻两周复权净值收益率。
   结果:
     62.02%
