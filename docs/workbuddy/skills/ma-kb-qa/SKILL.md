# 知识库问答

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」或「MA MOM数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 不要编造净值、持仓、观点或权限。工具因没有页面权限被隐藏或拒绝时，如实说明「当前账户没有该权限」，让用户去网站管理员处开通，而不是改用别人的身份。
4. 基金数据与 MOM 数据是两个连接器；需要哪边的数据就检查哪边是否已连接。


## 使用的 MCP 工具

连接器：MA 基金数据。账户需要「AI 知识库」权限。

- 问路演观点、看多看空：`kb_ask`。问观点时不要把 `model` 设为 turbo。
- 只要原文片段、不要结论：`kb_search`
- 读全文：`kb_read`（路径来自 `hits[].path` 或 citations，不要编造路径）
- 看有哪些文件：`kb_list`

## 执行步骤

1. 确认连接器和知识库工具可用。
2. 以 `citations` 里的 `quote`、`path`、`page` 为准。`citations_grounded` 为 false 时，不要把回答当成已核实。
3. 资料没写的任职或产品归属写成「资料未说明该关联」，不要推断。
4. `suggest_full_read` 为 true 或片段里没有答案时，再用 `kb_read`。
5. 填写「填表助手」那样的格子时，对每个单元格调用一次 `kb_ask`，不要一次编完整张表。
