# 单账户总览

本技能只使用「MA MOM数据」连接器上的单账户工具。表在 `public.cfmmc_*`，对应页面「单账户每日风控 → 单账户总览」。不要用 `mom_accounts` 或母基金核算回答这张表。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA MOM数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 不要编造账号、权益或风险度。工具因没有「MOM数据API」被拒绝时，如实说明，让用户去网站管理员处开通，而不是改用别人的身份。
4. 基金数据与 MOM 数据是两个连接器。本技能不使用基金数据 MCP。

## 使用的 MCP 工具

一次调用 `cfmmc_overview`。

- 全部账户：不传参数。
- 找某一家或某一只：传 `q`，例如 `银河期货`、产品名、资金账号或 PM。
- 按产品、期货公司或 PM 汇总：`group` 取 `fund`、`company` 或 `pm`。默认 `none`，一行一个账号。

要某一账号的完整净值序列时，再用 `cfmmc_account_nav`，`account` 和 `company` 用本表返回的账号和期货公司。不要为了画总览曲线去逐账号拉净值。

## 字段读法

直接引用 `rows` 和 `total`，不要重算合计。

| 字段 | 页面列 | 读法 |
| --- | --- | --- |
| fund_name | 私募基金 | 结算单客户名里的产品名 |
| company | 期货公司 | 简称，例如银河期货 |
| account | 账号 | 资金账号。分组行是「N个账号」 |
| pm | PM | 没有对应时为空 |
| equity | 动态权益 | 元 |
| margin | 保证金 | 元 |
| daily_pnl | 当日盈亏 | 元。客户权益差减去出入金 |
| holding_pnl | 浮动盈亏 | 元。当日盈亏减平仓盈亏，是当日变动，不是结算单持仓浮动水平 |
| closed_pnl | 平仓盈亏 | 元。结算单当日平仓盈亏 |
| risk_pct | 风险度 | 百分点。`11.86` 表示 11.86% |
| unilateral_risk_pct | 单边风险度 | 百分点 |
| commission | 手续费 | 元 |
| nav | 净值曲线 | 复权净值，从 1 起。分组行没有曲线 |
| nav_return_pct | 曲线累计收益 | 百分点，曲线首尾相除 |
| latest_nav | 最新复权净值 | 曲线最后一个点 |

`total.risk_pct` = 保证金合计 / 动态权益合计。`total.unilateral_risk_pct` 按动态权益加权。不要把各行风险度做平均。

每一行的 `trade_date` 是该账号最新已导入的交易日，各账号可以不同。`as_of` 是其中最晚的一天。

## 执行步骤

1. 确认 MOM 连接器已连接，且账户已开通 MOM数据API。401/403 时按登录规则处理。
2. 用户要总览、排名或合计时，只调用一次 `cfmmc_overview`。
3. 用户点名期货公司、产品或 PM 时，把这个词放进 `q`，或改 `group`。不要先拉全表再在本地猜测漏掉的账号。
4. 接口说数据尚未导入时，直接转告，不要改用母基金账户。

## 输出

先写截至日期和账号数。然后用表格列出产品、期货公司、账号、动态权益、当日盈亏、保证金和风险度。金额用元，风险度带百分号。最后一行用 `total`。用户要曲线时，用该行的 `nav`，并注明复权净值从 1 起。缺失写「接口未返回」。
