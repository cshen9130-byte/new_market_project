# 下载产品周报

用户要的是报告页「产品周报」上那一份文件。调一次工具，把返回的 PDF 或 PNG 保存后交给用户。不要打开文件重算，不要另写一份周报。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 没有投资池权限时如实说明。不要改用别人的身份。
4. 工具没有返回文件时，说明原因，不要自己画一份周报。

## 发文件

一次 `product_weekly_report`。

- `q` 用用户说的产品名或备案号，例如「金舆基石一号」。
- 没指定哪一周：不要传 `week_end`，工具给该产品最新一周。
- 用户指定某一周：传该周结束日 `week_end`，格式 `YYYY-MM-DD`。
- 默认 PDF。用户要图片时传 `format` 为 `png`。
- 名称对上多只产品时，工具会拒绝并列出名称。把这些名称列给用户，请他选一只，不要猜。
- 把 `content_base64` 解码，按 `file_name` 保存，把文件发给用户。不要把 base64 贴进对话。
- 回复写产品名、报告期（`week_start` 到 `week_end`）和文件名。文末可以放 `page_url`。

这是团队产品周报，和页面「团队报告」同一份。它不是跟踪池周度回顾 Excel，也不是 MOM 简报。

## 定时下载

用户要求定时保存某一只时，用技能目录里的 `download_product_weekly.py`。复制到该用户的 `%USERPROFILE%\WorkBuddy\scripts\`，不要留在带日期的 automation 目录，也不要写死 `Administrator`。

同目录写 `product-weekly.config.json`：

```json
{
  "mcp_url": "https://8.154.33.143/ma/api/fund-data/mcp",
  "key_file": "fund-data.key",
  "out_dir": "<这个用户的保存目录>",
  "q": "<产品名或备案号>",
  "format": "pdf"
}
```

`fund-data.key` 从这位用户本机 WorkBuddy MCP 配置里「MA 基金数据」的 `x-api-key` 读出，一行写入。不要把密钥写进脚本、任务正文或聊天。配置里没有密钥时停下来，请他用自己的账号连接。

保存目录没说时，用该用户的「文档\产品周报」。`out_dir` 写成这台电脑上的绝对路径。

定时任务正文只跑这个脚本，不调用 MCP 工具，不做分析。没另说时间时：每周五 09:10，长期有效，不推送到企业微信，权限「允许完全访问」。退出码 0 报告路径、大小，以及是新文件还是已存在跳过。退出码 1 说明 stderr，不要改用 MCP 重做。
