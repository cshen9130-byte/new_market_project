# 基金对比

本技能只使用「MA 基金数据」连接器的 `fund_compare`。这是投资分析页「基金对比」点分析之后的指标表，不是 `ai_researcher_compare`，也不是产品页的账户对比。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 工具不出现或提示没有「跟踪池」权限时，说明当前账户不能进入投资页。不要改用别人的身份，也不要改用 AI 研究员的对比工具充数。
4. 不要编造基金或收益。名称对应多只时，列出原因并请用户给备案号，不要自己挑一只。

## 调用

一次 `fund_compare`。

- `subjects`：两到八只，逗号分隔，产品名或备案号都可以。
- 不传区间时就是页面的默认：近一年、对齐起点、基准沪深300（`IF`）。
- 用户指定区间时传 `period`，或传 `start_date` 与 `end_date`。
- 用户不要基准时传 `benchmark=none`。换基准时传页面上的代码，例如 `IM` 中证1000、`IC` 中证500、`IH` 上证50。
- 用户说不要对齐起点时传 `align=0`。

页面「团队对比」里保存的组（例如「某某等 3 只」）只在那台浏览器里。不能按组名打开。请用户给出产品名或备案号后再调用。

`ai_researcher_compare` 读的是净值库固定窗口，还会查投资笔记。用户明确要基金对比页的区间表时不要调用它。

## 字段读法

直接引用，不要再乘 100，也不要用 `intervals` 重算 `rows`。

| 字段 | 页面列 | 读法 |
| --- | --- | --- |
| period_return_pct | 区间收益 | 百分点。`1.28` 表示 1.28% |
| ann_return_pct | 年化收益 | 百分点 |
| ann_vol_pct | 年化波动 | 百分点 |
| sharpe / calmar / sortino | 夏普、卡玛、索提诺 | 比率 |
| max_drawdown_pct | 最大回撤 | 百分点 |
| max_dd_recovery_days | 回撤修复 | 天数，或「未回补」 |
| intervals | 固定窗口表 | 近一周到近一年，同样是百分点。不是上面的所选区间 |

`is_benchmark` 为 true 的行是基准。`nav_scope` 为 `parent` 时，净值是母基金公布净值，不是单独份额净值。某只没有曲线时，对应数字为 null，写「接口未返回」。

## 输出

先写区间、是否对齐起点、基准名称，以及每只查询绑到了哪只基金。然后用表格列出区间收益、年化收益、年化波动、夏普和最大回撤。需要固定窗口时再另起一小节引用 `intervals`。不写成买卖建议。
