# 网站投资笔记

用户点名「投资笔记」时，搜的是网站「投资分析 → 投资笔记」里的笔记。AI 知识库里也有一个同名文件夹，那是已分享笔记的同步稿，不能代替这个页面。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 工具不出现或提示没有「AI 知识库」权限时，说明当前账户不能搜笔记。不要改用别人的身份。
4. 不要编造笔记正文。没有命中就说明投资笔记里没有这个词。

## 调用

先调用一次 `investment_note_search`。

- `q`：用户要找的词，例如「量衍」。
- 标题命中排在前面，正文里提到的笔记排在后面。两种都要告诉用户。
- `text` 是笔记正文。用户要「发给我」时，按 `text` 整理，不要改数字，不要用知识库稿替换。
- `url` 打开网站上的那一篇。回答最后把每篇的链接写成可点击的 markdown。不要自己编 `noteId`。

知识库可以另外查。`kb_search` 的 `folder_path` 填「投资笔记」只覆盖已分享到知识库的稿。页面上的笔记仍以 `investment_note_search` 为准。两处都有时，先给网站笔记和链接，再补充知识库里多出来的文件。

## 输出

先写找到几篇、各自标题，以及是标题命中还是正文提到。然后给出用户要的那篇正文。全文最后是网站链接。
