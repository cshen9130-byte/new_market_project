# MOM底层

本技能只使用「MA MOM数据」连接器的 `mom_underlying`。这是投资分析页「MOM底层」那张表，不是母基金核算账户列表，也不是单账户总览。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA MOM数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 不要编造产品、备案号、账号或权益。工具因没有「MOM数据API」被拒绝时，如实说明，让用户去网站管理员处开通，而不是改用别人的身份。
4. 基金数据与 MOM 数据是两个连接器。本技能不使用基金数据 MCP，也不要调用 `account_links`。

## 使用的 MCP 工具

一次调用 `mom_underlying`。

- 全表：不传参数。`compare_count` 是对比账户条数，`account_count` 是单账户条数。
- 只要对比账户：`kind=compare`。只要单账户：`kind=account`。
- 找某一只或某一个账号：传 `q`，例如产品名、备案号、`rx348` 或资金账号。

不要用 `mom_accounts` 回答「这只产品对应哪个底层账户」。`mom_accounts` 是母基金核算账号。不要用 `cfmmc_overview` 回答这张表。用户要改关联时，说明本接口只读，请到网站「MOM底层」页编辑。

要这只产品相对关联账户的超额和相关性时，改用基金数据连接器的技能 `ma-account-link`。本技能只给关联表本身。

## 字段读法

直接引用返回行，不要把涨跌幅再乘 100。

| 字段 | 页面列 | 读法 |
| --- | --- | --- |
| product_name | 产品名称 | |
| reg_code | 备案号 | |
| kind_label | 账户类型 | 对比账户或单账户 |
| account | 账户 | 对比账户如 rx348；单账户是资金账号 |
| account_note | 账户说明 | 没有则写「接口未返回」 |
| strategy | 策略 | |
| latest_nav | 最新单位净值 | 例如 2.6577 |
| latest_nav_date | 最新净值日期 | |
| price_change_pct | 最新涨跌幅 | 百分点。`-1.48` 表示 -1.48% |
| equity | 最新权益 | 元。对比账户是 MOM 客户权益，单账户是监控中心客户权益 |
| equity_date | 权益日期 | 页面不单列，回答时带上 |

`link_source` 为 `static` 时，这是内置对照，不是同事在页面上保存的关联。

## 执行步骤

1. 确认 MOM 连接器已连接，且账户已开通 MOM数据API。401/403 时按登录规则处理。
2. 用户要整张表、某一类或某一只产品时，只调用一次 `mom_underlying`。
3. 先看 `compare_count` 和 `account_count`，再列筛选后的 `rows`。

## 输出

先写全表里对比账户和单账户各有多少条。然后用表格列出产品、备案号、账户类型、账户、策略、最新净值、涨跌幅和最新权益。涨跌幅带百分号，权益用元。缺失写「接口未返回」。
