# 跟踪池与在管产品

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」或「MA MOM数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 不要编造净值、持仓、观点或权限。工具因没有页面权限被隐藏或拒绝时，如实说明「当前账户没有该权限」，让用户去网站管理员处开通，而不是改用别人的身份。
4. 基金数据与 MOM 数据是两个连接器；需要哪边的数据就检查哪边是否已连接。


## 使用的 MCP 工具

连接器：MA 基金数据。

- 跟踪池（需可进入投资页）：`tracking_pools`、`tracking_pool_list`、`tracking_pool_detail`
- `tracking_pool_detail` 里的 `team_note` / `personal_note` 是跟踪池短备注，不是投资笔记长文。
- 在管产品（需投资池权限）：`managed_products_list`
- 需要净值时，再用 `fund_price` 或 `fund_price_bulk`
- 外部业绩榜与跟踪池对比（需投资页且有 AI 知识库）：`external_rank_compare`

## 执行步骤

1. 确认基金数据连接器已连接。
2. 先 `tracking_pools` 看有哪些池，再按用户指定的池调用 list/detail。
3. 若 tools/list 没有跟踪池或在管产品工具，说明当前账户没有对应页面权限，请用户联系管理员开通，不要改用其它账号。
4. 不要把跟踪池短备注写成尽调结论。
