# 产品账户关联

本技能只使用「MA 基金数据」连接器。关联是只读的。不要新建、修改或删除关联。

## 登录与权限（必须遵守）

1. 只通过用户已经在 WorkBuddy 中连接的「MA 基金数据」MCP 调用本系统。不要手写 API Key，不要使用环境变量、文档、聊天记录或同事提供的 Key。
2. 若连接器未连接、授权失效，或工具列表为空/报 401，立即停止，请用户点击输入框上方的连接卡片（或到「专家·技能·连接器 → 连接器」里点击 +），用**自己的** MA 系统账号登录并允许授权。然后继续当前任务，不要换一种未授权的方式重试。
3. 不要编造备案号、账号、收益或相关性。工具拒绝时如实说明，让用户去网站管理员处开通，而不是改用别人的身份。
4. 基金数据与 MOM 数据是两个连接器。本技能不调用 MOM 连接器，也不要用 `mom_account_metrics` 或 `mom_risk_var` 代替账户对比。

## 使用的 MCP 工具

- 先找关联：`account_links`（可选 `q`、`kind`）
- 再算对比：`account_link_compare`（必填 `reg_code`）

`kind=compare` 是 MOM 对比账户。`kind=account` 是单账户监控中心资金账号。列表里的 `account_id` 原样传给对比工具。单账户的 `account_id` 形如 `cfmmc:807636`。不要把资金账号当成 MOM 账户代码。

不传 `account` 时，对比工具使用该产品已保存的关联，MOM 关联优先于单账户。`used_saved_link` 为 true 表示这次用的是保存的关联。没有关联时接口会说明，不要猜一个账号。

名称不确定时先 `fund_search`，再用返回的备案号。

## 字段读法

直接引用 `summary`，不要用 `curve` 重算。

- `fund_period_return_pct`、`account_period_return_pct`、`excess_return_pct`、`tracking_error_pct`、`hit_rate_pct`：`1.28` 表示 1.28%，不是 0.0128。超额 = 产品区间收益 − 账户区间收益。
- `correlation`、`information_ratio` 是比率。`0.49` 就是 0.49。
- `curve[].fund_pct`、`account_pct`、`excess_pct` 也是百分数。重叠第一天是 0。用户要曲线时用这三列，不要再请求一遍净值。
- 默认产品线是复权净值。用户指定单位净值或累计净值时才传 `nav=unit` 或 `nav=accumulated`。
- `freq` 默认 `all`。只有用户明确说周频或月频时才改。
- `truncated` 为 true 时说明净值被截断，不要把这段当成完整区间。把日期收窄后重取一次。

口径与产品页「账户对比」相同：MOM 账户按结算日报日复利；单账户用客户权益路径复权净值，出入金不计入收益；相关性和跟踪误差只在产品净值披露日配对。接口 `note` 已写明，按它解释，不要另起算法。

## 执行步骤

1. 确认基金数据连接器已连接。401 时按登录规则处理。
2. 用户问「哪只产品挂了哪个账户」时，只调用 `account_links`。
3. 用户问超额、相关性、跟踪误差或累计收益对比时，调用一次 `account_link_compare`。日期用用户给出的区间。
4. 同一产品既有 MOM 关联又有单账户时，先说明默认用的是哪一个。用户点名单账户或期货公司资金账号时，传对应的 `account_id`。

## 输出

先写产品名、备案号、账户标签（`account.label`）、重叠区间。

再用一行给出产品区间收益、账户区间收益、超额、相关性和跟踪误差，数字来自 `summary`。要图时画 `curve`，纵轴用百分数，起点为 0。缺失写「接口未返回」。
